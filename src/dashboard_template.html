Historical news index comparison

This separate test uses the San Francisco Fed’s published historical news index, averaged over month t−2. Economic inputs use archived vintages, but historical news-index vintages were not recovered. These are retrospective comparisons, not verified real-time media forecasts.

Across the full window, adding the index changes dynamic-model RMSE from 5.19 to 5.23. A 2021-onward sensitivity changes 4.78 to 4.71. The evidence does not establish a stable operational gain or a causal effect.

Data quality and interpretation

Definitions and update instructions

The sentiment gap is observed sentiment minus the selected model's prediction. A negative gap is unexplained under that model. It does not establish irrationality or media bias.

To update this dashboard, refresh the project datasets, run the analysis and dashboard builder, then open the regenerated file. The snapshot picker also accepts results/dashboard_snapshot.json from a later run. Refreshing data does not automatically validate the text model.

Source files, exact vintage dates, collection searches, model specifications and limitations are documented in the project package.
